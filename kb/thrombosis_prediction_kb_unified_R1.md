## KB-001
- 상황: 환자 단위로 리스트업할 때 중복을 피해야 하는 질문
- 키워드: 환자, 리스트업, DISTINCT, 중복
- 교정 내용: 처음에는 중복된 환자 ID가 나올 수 있는 쿼리를 작성했으나, DISTINCT를 사용하여 중복을 제거해야 한다는 힌트를 받아 수정함.
- 예외: 환자 ID가 유일한 경우, DISTINCT를 사용할 필요가 없음.

## KB-002
- 상황: 평균 계산 시 중복된 환자를 세지 않아야 하는 질문
- 키워드: 평균, 중복, 환자, 검사기록
- 교정 내용: 처음에는 서브쿼리를 사용하여 중복된 환자 ID만 걸러내는 방식으로 평균을 계산했으나, 직접 조인하여 조건을 만족하는 검사기록을 기준으로 평균을 내야 한다는 힌트를 받아 수정함.
- 예외: 모든 환자가 검사기록을 가지고 있는 경우, 서브쿼리를 사용해도 무방할 수 있음.

## KB-003
- 상황: 특정 컬럼이 다른 테이블에 있을 때 조인해야 하는 질문
- 키워드: SC170, Examination, Laboratory, 조인
- 교정 내용: 처음에는 SC170 컬럼이 Examination 테이블에 있다고 잘못 판단하여 쿼리를 작성했으나, Laboratory 테이블에 있어야 한다는 힌트를 받아 수정함.
- 예외: SC170이 Examination에만 있는 경우, 조인할 필요가 없음.

## KB-004
- 상황: 특정 조건을 만족하는 환자의 수를 세는 질문
- 키워드: 두 번 이상, COUNT, HAVING
- 교정 내용: 처음에는 COUNT(ID) > 2로 잘못 작성했으나, COUNT(ID) >= 2로 수정해야 한다는 힌트를 받아 수정함.
- 예외: COUNT가 2인 경우도 포함해야 하는 상황.

## KB-005
- 상황: 특정 조건을 만족하는 환자 리스트업 시 중복을 피해야 하는 질문
- 키워드: UN, 리스트업, DISTINCT
- 교정 내용: 처음에는 중복된 환자 ID가 나올 수 있는 쿼리를 작성했으나, DISTINCT를 사용하여 중복을 제거해야 한다는 힌트를 받아 수정함.
- 예외: 환자 ID가 유일한 경우, DISTINCT를 사용할 필요가 없음.

## KB-006
- 상황: 날짜 비교 시 연도만 추출하여 비교해야 하는 질문
- 키워드: Birthday, 날짜, STRFTIME
- 교정 내용: 처음에는 날짜를 직접 비교했으나, STRFTIME('%Y', Birthday)로 연도만 추출하여 비교해야 한다는 힌트를 받아 수정함.
- 예외: 날짜 형식이 일관된 경우 직접 비교해도 무방할 수 있음.

## KB-007
- 상황: 특정 조건을 만족하는 환자의 수를 셀 때 DISTINCT를 사용해야 하는 질문
- 키워드: COUNT, DISTINCT, 환자, CRE
- 교정 내용: 처음에는 COUNT(*)로 모든 행을 세는 쿼리를 작성했으나, COUNT(DISTINCT ID)를 사용해야 한다는 힌트를 받아 수정함.
- 예외: 모든 환자가 유일한 경우 COUNT(*)를 사용해도 무방할 수 있음.
